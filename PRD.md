# Product Requirements Document (PRD): Rehumanise

## 1. Overview

**Rehumanise** is a web application that helps students and writers bypass AI detection tools by transforming AI-generated text into more human-like writing. The platform leverages Next.js 15 for performance, security, and extensibility, targeting users who need to ensure their content appears authentically human.

---

## 2. Goals & Objectives

- Enable users to check if their text is likely to be flagged as AI-generated.
- Provide a tool to rewrite AI-generated content to sound more natural and human.
- Deliver a fast, secure, and user-friendly experience.
- Support SEO and marketing strategies for discoverability and growth.

---

## 3. Target Audience

- Primary: Students submitting assignments or essays.
- Secondary: Writers, professionals, and anyone needing to humanise AI-generated text.

---

## 4. Functional Requirements

### 4.1 Core Features

- **AI Detection Tool**
  - Input: User pastes or types text.
  - Output: Analysis showing likelihood of being flagged as AI-generated.
  - Reference popular detection tools for benchmarking.

- **Humanise Tool**
  - Input: User pastes or types AI-generated text.
  - Output: Rewritten text that is more natural and human-like.
  - Option to copy or export the result.
